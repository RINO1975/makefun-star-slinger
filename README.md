Star Slinger is an original gravity-slingshot puzzle game. Drag the comet to aim (a dotted preview shows the flight under gravity), release to launch, bend your flight around planets, collect every star, then enter the goal halo to finish the level. 10 handcrafted levels, 3 shots per level, synth WebAudio sounds — plain 2D canvas, no libraries, no network, runs offline in a desktop browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
